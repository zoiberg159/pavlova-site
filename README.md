# Макет сайта кафе-кондитерской «Павлова»

Одностраничник для кафе-кондитерской «Павлова» (Москва, Родионовская ул., 12).
Показывается владелице как макет до заключения договора.

- Весь сайт — один файл `index.html`, без сборки и зависимостей.
- Иллюстрация десерта нарисована в SVG, внешних картинок нет.
- Данные (меню, часы, контакты, рейтинг) взяты с карточки на Яндекс Картах,
  цены и отзывы согласовываем с владелицей перед публикацией.

Опубликовано через GitHub Pages: Settings → Pages → ветка `main`, папка `/ (root)`.

Рабочая копия и история правок живут в основном рабочем репозитории, в папке `pavlova/`.
